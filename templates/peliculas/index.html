Importar Catálogo de Películas

Suba un archivo CSV o JSON para añadir o actualizar el catálogo de películas. Los registros existentes con el mismo **título** serán actualizados.

**Formato Esperado:** El archivo debe tener las columnas: `titulo`, `duracion`, `genero_nombre`, `disponible`, etc. Se recomienda **exportar un archivo primero** para ver el formato correcto.
